# Local acceptance evidence

Generated receipts and browser captures in this directory remain on the operator's device and are excluded from Git. They may contain local account metadata, private screenshots or runtime-specific facts. Source, tests, runbooks and the expanded task history are versioned; databases, private uploads, encryption keys, credentials, dependency caches and REPL history are not.

Links in deployment reports refer to the retained local artifacts. An absent receipt on a fresh clone does not authorize bypassing its guard or replaying a completed writer. Use the current task's scoped acceptance procedure with its own synthetic fixtures and authorization. Historical proof applies only to the exact sources and runtime recorded in that proof.
