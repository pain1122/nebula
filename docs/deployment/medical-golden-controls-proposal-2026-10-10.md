## Scope and safeguards

This approval covers the above remaining medical form/control composition together so each small verified implementation does not need another design-permission cycle. The new source-only write adapter passes52files/328tests and uses explicit input whitelists, existing session/CSRF/abort transport and scoped success invalidation; rejected/ambiguous operations do not automatically replay. Publication uses the service, never manual clean/paid/completed updates.

The current pending-outcome message is honest until that contract is delivered. Separate upload reception, pending checks, eligibility and publication; show no raw engine/path/checksum/retention information. Disable repeated submits while pending; cancellation/network ambiguity requires an ordinary refresh/check before another user-directed write.

Dedicated worker/demo activation remains a separately verified runtime slice. Operator performs Compose; consume only medical-scan jobs and retain real content/engine/freshness/integrity safeguards. Main scanning is still false today; no worker or clinical write is implied by approving form composition. Fixed questionnaire and final full rehearsal remain subsequent minimum-demo items, not additional medical permission gates.
